# Tecnologías y Librerías Utilizadas

Este documento detalla todas las herramientas y librerías que hacen posible el funcionamiento del Sistema de Inventario QR.

## 💻 Frontend (Interfaz de Usuario)

| Librería | Propósito |
| :--- | :--- |
| **React** | Biblioteca principal para la construcción de la interfaz. |
| **Vite** | Herramienta de construcción y servidor de desarrollo ultra rápido. |
| **Tailwind CSS** | Framework de CSS para un diseño moderno y responsive. |
| **Radix UI** | Componentes primitivos accesibles (Modales, Selects, etc.). |
| **Lucide React** | Pack de iconos vectoriales ligeros. |
| **React Query** | Gestión de estado y caché para las peticiones a la API. |
| **React Router** | Navegación entre las diferentes páginas de la aplicación. |
| **Zod** | Validación de esquemas de datos y formularios. |

## ⚙️ Backend (Servidor)

| Librería | Propósito |
| :--- | :--- |
| **Node.js** | Entorno de ejecución para el servidor. |
| **Express** | Framework web para manejar rutas y APIs. |
| **MySQL2** | Cliente para la comunicación con la base de datos MySQL. |
| **Bcryptjs** | Encriptación de contraseñas de forma segura. |
| **Multer** | Manejo de subida de imágenes y archivos al servidor. |
| **Compression** | Middleware para comprimir las respuestas del servidor (GZIP/Brotli). |
| **Dotenv** | Gestión de variables de entorno (configuraciones secretas). |

## 📱 Funcionalidades Especiales

| Librería | Propósito |
| :--- | :--- |
| **Capacitor** | Permite convertir la aplicación web en una app nativa para Android. |
| **jsPDF** | Generación de documentos PDF desde el navegador. |
| **AutoTable** | Extensión para jsPDF que facilita la creación de tablas en reportes. |
| **html5-qrcode** | Librería para el escaneo de códigos QR mediante la cámara. |
| **qr-code-styling** | Generación de códigos QR estéticos con soporte para logos. |
| **ExcelJS** | Creación y manipulación de archivos Excel (XLSX). |

## 🛠️ Herramientas de Desarrollo

-   **TypeScript**: Superconjunto de JavaScript que añade tipado estático para evitar errores.
-   **PNPM**: Gestor de paquetes eficiente y rápido.
-   **ESLint / Prettier**: Mantienen el código limpio y con un formato consistente.
-   **Terser / Esbuild**: Herramientas para minificar el código y reducir el tamaño de la app.
